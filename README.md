# Nourbelletours

## Run and build

Install dependencies once:

```bash
npm install
```

**Development** (local server with hot reload):

```bash
npm run dev
```

**Production build**:

```bash
npm run build
```

**Production server** (serve the built app; run `npm run build` first):

```bash
npm run start
```

**Lint**:

```bash
npm run lint
```
